Create a production-quality web application called **EasyDrop** — a smart nearby-device information-sharing platform.

The application should feel like a **real modern SaaS/startup product**, not a basic college project.

### 1. CORE CONCEPT

EasyDrop allows a user to:

**Create a session → Discover nearby devices → Select a device → Confirm connection → Generate QR → Scan QR → Connect → Select information → Preview → Share → Track transfer → Complete → Securely end session**

The main goal is to make sharing information between nearby devices **fast, simple, secure and intuitive**.

# 3. TECHNOLOGIES

Build the frontend using:

### Frontend

* **HTML5** — page structure
* **CSS3** — styling, responsive design and animations
* **JavaScript (ES6+)** — application logic and interactions
* **Tailwind CSS** — modern responsive UI styling
* **Lucide Icons** — clean interface icons
* **Google Fonts / Inter** — typography

### QR functionality

Use a JavaScript QR library such as:

* **QRCode.js** for QR generation
* **html5-qrcode** or another suitable browser QR solution for scanning

### Real-time communication / future backend

For the actual sharing system, design the architecture so it can later support:

* **WebRTC** — peer-to-peer device communication
* **WebSocket / Socket.IO** — real-time connection and session status
* **Node.js + Express.js** — backend API
* **MongoDB / Firebase** — temporary session information if required

### Important browser limitation

Do not falsely claim that a normal website can automatically discover every nearby phone or laptop.

For the frontend prototype, create a **realistic simulated nearby-device discovery experience**.

For the production version, structure the application so WebRTC, WebSocket, local-network discovery, QR-based session pairing and supported browser APIs can be integrated later.
