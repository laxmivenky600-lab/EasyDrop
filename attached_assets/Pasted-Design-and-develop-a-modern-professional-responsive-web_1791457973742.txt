Design and develop a modern, professional, responsive web application called **EasyDrop** — a fast and simple QR-based file-sharing platform.

### Product Concept

EasyDrop allows one device to send files to another device without searching for nearby devices.

The sender creates a temporary transfer session and generates a QR code. The receiver scans the QR code, opens the secure transfer session, and receives the selected files. After the transfer is completed, the receiver can download the files.

### Core Experience

**Scan → Connect → Select → Send → Download**

Do NOT include:

* Nearby device discovery
* Nearby device lists
* Bluetooth device scanning
* Device radar
* Manual device searching

The QR code is the primary connection and pairing mechanism.

# 16. Technologies

### Frontend

* HTML5
* CSS3
* JavaScript ES6+
* Tailwind CSS
* Lucide Icons
* Inter Font

### QR Code

For QR generation:

**QRCode.js**

For QR scanning:

**html5-qrcode**

### Real-Time Communication

Use:

**WebSocket / Socket.IO**

for session creation, connection status, and transfer signaling.

### File Transfer

Use:

**WebRTC**

for peer-to-peer file transfer where appropriate.

### Backend

Use:

**Node.js + Express.js**

for:

* Temporary session creation
* Session IDs
* QR pairing
* Signaling
* Connection management
* Session expiration

Do not store transferred files permanently unless explicitly required.
